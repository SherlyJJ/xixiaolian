# 小联帮你链交互原型 v0.6

本目录保存当前对话最终确认的小联帮你链高保真交互原型。原型采用单文件静态实现，页面、组件、样式、路由状态、Mock 数据与内联 SVG 图标均收敛在 [`index.html`](./index.html) 中，便于直接运行和评审。

## 运行

直接使用浏览器打开 `index.html`，或在本目录启动静态服务器：

```bash
python3 -m http.server 4173
```

访问 `http://localhost:4173/`。

## 检查

需要 Node.js 18 或更高版本，无需安装第三方依赖：

```bash
npm run check
```

检查内容包括：

- HTML、CSS、JavaScript 主区块完整；
- 内联 JavaScript 可通过语法编译；
- 会员、无发布权限会员、工商联和公司内部 PC 后台角色入口存在；
- 四种发布录入方式和五种找项目展示样例存在；
- 公众号授权、文章合集、单篇文章、小程序长期链接、网页解析和项目介绍关键状态存在；
- 20 项分类字典完整；
- 项目状态规则与关键操作函数存在。

## 主要文件

- `index.html`：可运行交互原型源代码。
- `docs/interaction-spec.md`：页面、组件、路由、状态、Mock 数据和交互规格。
- `assets/README.md`：图片和图标资源说明。
- `tests/smoke.mjs`：零依赖基础检查。
- `package.json`：检查与本地运行命令。

## 基线范围

- 发布录入方式：公众号文章、微信小程序页面、网页链接、项目介绍。
- 找项目展示样例：公众号文章合集、公众号单篇文章、微信小程序、网页链接、联系对接。
- 项目状态：未上架、已上架；未上架可编辑、上架、删除，已上架只允许下架。
- 统一分类：20 项固定分类字典，由解析结果推荐 1—3 项并允许人工调整。

## 已知限制

- 所有内容与接口结果均为 Mock，不连接真实后端、微信授权或文章接口。
- 二维码点击仅模拟扫码和授权状态变化。
- 小程序长期 URL Link 只做格式和流程演示，不能独立验证真实有效期。
- 小程序内实际跳转仍需技术侧确认目标 AppID 与页面路径的保存和调用方案。
- 网页反爬成功或失败为手动演示分支，没有真实抓取网页。
- 原型没有持久化数据；刷新页面会恢复初始状态。
- PC 后台、工商联端和会员端仅覆盖本次需求确认范围，不代表完整生产系统。
