# 小联帮你链 v0.6 交互规格

## 1. 成果定位

本原型用于说明“小联为你办”能力并入“小联帮你链”后的前端信息架构、项目录入、项目浏览和项目管理流程。“项目”是统一业务名称，服务内容以项目形式发布和展示。

原型为零构建依赖的单页静态应用。`index.html` 内包含样式、内联 SVG、Mock 数据、状态对象、页面渲染函数和交互处理函数。

## 2. 角色

| 角色 | 首页常用功能 | 管理范围 |
| --- | --- | --- |
| 会员（有发布权限） | 发布项目、我的项目、找企业 | 创建和管理本企业项目 |
| 会员（无发布权限） | 找企业 | 只能浏览项目和企业，不显示发布项目、我的项目 |
| 工商联 | 项目管理、找企业 | 监管项目；已上架项目只允许下架 |
| 公司内部 PC 后台 | 项目管理、新建项目 | 选择所属会员企业并按相同规则创建、编辑、上架、下架、删除 |

## 3. 页面与路由状态

移动端没有 URL 路由，使用 `state.page` 与页面栈 `state.stack` 模拟小程序页面跳转。

| `state.page` | 页面 | 主要组件/渲染函数 |
| --- | --- | --- |
| `home` | 小联帮你链首页 | `home`、`categoryBar`、优质项目推荐、常用功能 |
| `list` | 找项目 | `list`、搜索框、20 项分类筛选、项目卡片 |
| `types` | 选择项目录入方式 | `typeSelect`、四种录入方式卡片 |
| `form` | 发布/编辑项目 | `form`、`sourceForm`、`editableInfo` |
| `detail` | 项目详情 | `detail`、不同内容形态的通用详情底板 |
| `manage` | 我的项目/项目管理 | `manage`、状态筛选、状态对应操作 |

PC 后台使用 `state.adminPage`：

- `list`：项目管理列表；
- `types`：选择录入方式；
- `form`：新建或编辑项目。

## 4. 发布录入方式

发布入口只有四种，字典值决定来源录入交互，不等同于20项业务分类。

| 字典值 | 用户选择文案 | 来源交互 | 解析结果 |
| --- | --- | --- | --- |
| `official_account_articles` | 我有公众号文章 | 微信二维码授权后选择全部或部分文章 | 公众号资料、项目名称、简介、分类和文章封面候选 |
| `mini_program_link` | 我有微信小程序页面 | 平铺长期 URL Link 获取指引，粘贴并校验 | 链接无法拆解项目资料，必要字段保持空并人工补录 |
| `external_web` | 我有一个网页链接 | 输入 HTTPS 链接，演示成功或反爬失败 | 成功时读取网页资料与 OG 图候选；失败时人工补录 |
| `basic_info` | 我只有项目介绍 | 文字、语音、图片/PDF/Word 可组合输入 | 综合解析项目名称、简介和分类 |

## 5. 公众号授权与文章导入状态

`state.authStage` 状态流：

1. `idle`：展示“发起授权”；
2. `qr`：展示微信公众平台授权二维码；
3. `scanning`：点击二维码后显示扫码确认动画；
4. `success`：显示授权成功反馈；
5. `done`：加载公众号资料与全部 Mock 文章。

授权成功后显示12篇文章，列表只展示标题、发布时间、公众号和封面，不在选择阶段展开正文摘要。

- 导入全部：导入现有文章，并说明后续新增文章自动同步；
- 选择部分：支持单篇或多篇，不自动导入后续新增文章。

## 6. 找项目展示样例

发布录入方式与找项目展示样例分离。当前 `projectSamples` 包含五类展示：

1. 公众号文章合集：详情平铺12篇文章，文章可逐篇打开，底部进入对方公众号主页；
2. 公众号单篇文章：独立项目详情，展示公众号来源、发布时间、封面和内容摘要，底部阅读原文；
3. 微信小程序：通用详情底板，底部立即体验；
4. 网页链接：通用详情底板，根据域名条件立即体验或复制网址；
5. 联系对接：通用详情底板，底部联系项目联系人。

## 7. 统一结果字段

所有录入方式进入人工确认区后使用通用字段底板：

- 所属企业；
- 项目名称；
- 项目简介；
- 1—3 个分类标签；
- 宣传图片；
- 相关附件；
- 来源对应字段：公众号授权、长期小程序链接、H5链接或联系人姓名与电话。

字段来源规则：

- 会员所属企业由当前账号读取且不可修改；PC 后台由工作人员选择；
- 项目名称和简介由来源解析，解析失败时为空，可人工填写和修改；
- 公众号文章封面、网页 OG 图、材料首页图只作为宣传图片候选，必须由用户确认或自主上传；
- 小程序、纯文字和语音不自动产生宣传图片；
- 相关附件不从来源自动生成，默认留空，用户点击上传后才挂接示例文件。

## 8. 分类字典

主页推荐、找项目、PC 后台筛选和 AI 推荐统一使用以下20项：

软件服务、硬件制造、咨询服务、研发创新、运营维护、创意制作、成品销售、定制方案、外包服务、企业方案、消费服务、公共项目、培训服务、工程建设、材料供应、数字营销、数据智能、安全合规、供应链管理、环保可持续。

解析结果只能从字典中推荐1—3项，用户可以调整但不能自定义新分类。

## 9. 项目状态

| 状态 | 允许操作 |
| --- | --- |
| 未上架 | 编辑、上架、删除 |
| 已上架 | 下架 |

新建项目统一保存为未上架。下架后恢复编辑、上架和删除能力。原型不包含审核状态。

## 10. Mock 数据

`index.html` 中的主要 Mock 数据：

- `categories`：20项分类字典；
- `types`：四种发布录入方式；
- `articleSamples`：12篇公众号文章；
- `singleArticleProject`：公众号单篇文章展示样例；
- `projectSamples`：找项目五种展示样例；
- `state`：角色、页面、授权、解析、输入材料、宣传图、附件和管理页面状态。

项目、企业、联系人、文章、URL Link、网页地址及附件均为演示数据。

## 11. 已完成检查

- 原型 HTML、CSS、JavaScript 主区块存在；
- 内联 JavaScript 可通过 Node.js 语法编译；
- 四角色、六个移动端页面状态及三个 PC 后台页面状态存在；
- 四种发布录入方式、五种找项目展示样例和20项分类完整；
- 公众号授权状态流、12篇文章列表、合集与单篇详情存在；
- 小程序三种链接输入示例、网页成功/失败分支、文字/语音/文件组合输入存在；
- 未上架与已上架操作规则存在。

运行 `npm run check` 可重复执行基础检查。

## 12. 已知限制

- 不连接微信、AI、网页解析、文件解析、语音识别、电话或后台 API；
- 二维码、打开公众号、阅读原文、打开小程序和复制网址均为交互反馈；
- URL Link 格式正确不等于真实长期有效；
- 详情页“立即体验”所需 AppID 与页面路径仍需技术确认；
- CSS 渐变为封面和宣传图片占位，不代表最终视觉素材；
- 原型无数据持久化、登录、权限接口或真实错误重试机制；
- 未新增审核、审批、工商联差异化权限等未确认能力。
